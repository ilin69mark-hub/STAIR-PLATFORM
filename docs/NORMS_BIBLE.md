## Приложение А. Что из библии применяется в коде сегодня (проверено 2026-10-13)

Движок проверяет ТОЛЬКО 7 размерных правил (`constraint/standard.go`,
профиль STANDARD по EDR-0002) + шаг комфорта 600–640 (формула Блонделя
`2h+b`, без ссылки). С S-235 у каждого правила есть источник
(`constraint.Source`) — и, что важнее, честно разделены основания:
норма (`norm`), эргономика (`ergonomics`), производство
(`manufacturing`). Пустой источник правило не принимает: гейт.

| правило кода | значение | основание | источник в коде (S-235) |
|---|---|---|---|
| высота ступени 150–200 | error | эргономика | антропометрия шага; нормативный предел — в профилях (S-236) |
| проступь 260–320 | error | эргономика | антропометрия; ГОСТ 23120 — по назначению |
| угол 30–45° | error | норма | ГОСТ 23120 (предельный уклон); 30° — эргономическая граница, пункт уточняется |
| просвет ≥2000 | warning | норма | СП 59.13330, СП 54/118; пункт уточняется |
| косоур лист 3–8 | warning | производство | MFG-0005, раскрываемый сортаж листа |
| косоур дерево ≥30 | warning | производство | ГОСТ 8486/24454; прочности пока нет (S-237) |
| ограждение ≥900 | **warning** | норма | ГОСТ 25772-2025 (жилое); пункт уточняется; warning → error в профилях (S-239) |
| шаг комфорта 600–640 | error | эргономика | формула Блонделя 2h+b, вне constraint |

Чего нет вообще: нагрузки (п. 1, 77), прочность/устойчивость (п. 78),
прогибы (п. 79), болты/сварка/анкеры расчётом (п. 80–81), эвакуация
и пожарка (п. 10, 15), доступность как профиль (п. 16), база стекла
(п. 70), профили по назначению здания закрыты S-236. П. 30 (сварка) — код
варит только в кавычках: сварных швов в модели нет.

## Приложение В. Прочностные характеристики материалов (S-237b, 2026-10-14)

Первое наполнение из ТЕКСТОВ НОРМ, а не из справочников. Оба свода
выверены по официальным текстам, редакции зафиксированы.

### Сталь — СП 16.13330.2017 (приказ Минстроя № 126/пр, ред. от 27.06.2023)

| величина | значение | источник |
|---|---|---|
| Ryn (предел текучести) | 245 Н/мм² | табл. В.3, С245, толщина 2,0–20 мм вкл. |
| Run (временное сопротивление) | 370 Н/мм² | табл. В.3 |
| E | 2,06·10⁵ Н/мм² | прил. Б, табл. Б.1 |
| G | 0,79·10⁵ Н/мм² | прил. Б, табл. Б.1 |
| ν | 0,3 | прил. Б, табл. Б.1 |
| γm | 1,05 | табл. 3, «остальной прокат» |

**Решение по классу: S235 заменён на С245.** В табл. В.3 S235 есть только
для толщины 2,0–4,0 мм, а каталог MFG-0005 выпускает лист 3–12 мм: половина
диапазона попадала в класс, для которого таблица не даёт значений. С245
покрывает 2,0–20 мм, то есть весь диапазон каталога целиком. Правка кода
материала потребовала миграции данных (000050): код попадает в
`stair_configurations.material_code`, `tread_material_code` и
`store_rates.material_code`, а также в путь свача `assets/pbr/<code>/`.

В коде хранятся НОРМАТИВНЫЕ сопротивления (Ryn/Run), а не расчётные
(Ry/Ru): расчётные получаются делением на γm по п. 6.1. Хранить оба вида
сразу — верный путь к двойному учёту коэффициента.

**Не покрыто нормой:** труба поручня Ø42,4×1,5 — толщина стенки 1,5 мм
ниже нижней границы табл. В.3 (2,0 мм). Для неё в СП 16 строки нет.

### Древесина — СП 64.13330.2017 (приказ Минстроя № 129/пр, ред. от 28.12.2023)

Расчётные сопротивления по п. 6.1: `Rр = RА · mдл · Пmi`. Режим нагружения
**В** (табл. 4, `mдл = 0,66`) — постоянная, длительная и временная нагрузки
плюс нагрузки от людей на перекрытиях жилых и общественных зданий; для
лестницы это рабочий режим. Класс эксплуатации 2 (табл. 9, `mв = 1,0`) и
срок службы ≤50 лет (табл. 13, `mс.с = 1,0`) дают `Пmi = 1,0`.

| величина | сосна/ель сорт 1 | дуб (mп 1,3 / 2 / 1,3) | табл. 3 |
|---|---|---|---|
| изгиб, сжатие вдоль | 21 × 0,66 = **13,86** | × 1,3 = **18,02** | поз. 1а |
| растяжение вдоль | 15 × 0,66 = **9,90** | × 1,3 = **12,87** | поз. 2а |
| смятие поперёк местное | 4,5 × 0,66 = **2,97** | × 2 = **5,94** | поз. 4а |
| скалывание вдоль | 2,7 × 0,66 = **1,78** | × 1,3 = **2,32** | поз. 5а |
| E0,ср | 10 ГПа = **10 000** | **нет в СП 64** | прил. В.2 |

Переходные коэффициенты `mп` (табл. 5): дуб 1,3/2/1,3; ясень 1,3/2/1,6;
берёза, бук 1,1/1,6/1,3. **Орех в табл. 5 отсутствует.**

Взят НАИМЕНЬШИЙ ряд табл. 3 для прямоугольного сечения (поз. 1а, 21 МПа):
ряды 1б и 1в дают 22,5 и 24 МПа для конкретных ширины и высоты, а ориентация
сечения расчёту пока не передаётся. Значение не завышает ни при каком
случае.

### Три дыры, которые остаются дырами

1. **E для дуба и ясеня в СП 64 нет.** Прил. В.2 даёт модуль только сосне и
   ели, табл. В.3 — по классам прочности C14…C50, но не по породам. Наборы
   дуба и ясеня имеют статус `partial`: расчёт по деформациям для них не
   выполняется. Подставлять сосновые 10 ГПа — значит выдать чужое значение за
   нормативное дуба.
2. **п. 5.1 СП 64 (ред. 4, с 29.01.2024) запрещает дуб в несущих ДК.**
   Формулировка: для изготовления ДК — древесина хвойных пород; твёрдые
   лиственные — для LVL, нагелей, подушек и «других деталей». Применение
   дуба как основного материала лестницы оставлено решением владельца
   2026-10-14 и помечено в `Mechanicals.Source`, чтобы расчёт мог сослаться
   на отклонение, а не сделать вид, что его нет.
3. **Орех (`WOOD-WALNUT`) в СП 64 не упомянут ни разу** — ни сопротивлений,
   ни `mп`, ни плотности. Набор пуст, статус `unknown`.

### Чего всё ещё нет

Нагрузки и сочетания (п. 77), сам расчёт прочности и устойчивости (п. 78),

проверка соединений. Полное ТЗ на прочностные поля — п. 68–70.

## Приложение Б. Блокеры расчёта «так нельзя» (безопасность)

1. **Нет расчётной схемы.** Площадка висит в воздухе, балок и опор нет —
   считать нечего (см. пласт «площадка» S-226…S-234).
2. **Нет нагрузок.** Ни постоянной/временной, ни сочетаний (п. 77) —
   нечего прикладывать.
3. **Нет характеристик материалов.** В каталоге размеры и цены, сопротивлений
   нет (п. 68–70). Маркетинг витрины («просчитывается по нагрузкам»,
   `Landing.tsx`) — враньё, заведено к удалению (S-234 п.5).
4. **Нет типов узлов.** Болты/анкеры считаются штуками, не напряжениями
   (п. 86–87); отверстий под расчёт нет.
5. **Ограждение ≥900 — warning, не error.** Лестницу ниже 900 можно
   выпустить — по п. 9 это брак. Нужен error или профиль по назначению.
6. **Нет профилей по назначению** (п. 67): жилое/общественное/производственное
   проверяются одинаково — так нельзя.
7. **BC-002/BC-005 — не запреты.** Это ID bounded-контекстов (DDD),
   а не «геометрии запрещено считать прочность». Запрета нет — нет кода.
   Инженерное расширение прямо предусмотрено (EDR-0033).
