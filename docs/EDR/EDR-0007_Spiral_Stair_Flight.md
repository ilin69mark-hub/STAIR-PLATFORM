# 1. Purpose

Документ фиксирует математическую модель расчёта спиральной (винтовой)
лестницы (spiral flight) с центральной колонной.

Документ является единственным источником инженерных формул (ADR-0003)
для спирального марша; формулы прямого марша — EDR-0001.

# 3. MDL (Math Model)

## Концепция

Спиральная лестница с центральной колонной состоит из:

- **центральной колонны** (column) — вертикального цилиндра радиуса `r`,
  опоры всех ступеней;
- **n веерных ступеней** (treads) — клиновидных секторов кольца между
  колонной (`r`) и наружным радиусом (`R`), поднимающихся по винтовой
  линии на полный оборот (360°).

Ступени крепятся к колонне и образуют винтовую линию: каждая следующая
ступень повёрнута на угловой шаг `δ` и поднята на высоту `h`.

Проступи не являются прямоугольниками: их глубина меняется по радиусу.
Комфорт измеряется по **линии хода** — дуге на расстоянии 2/3 ширины
марша от колонны (нормативная практика).

Подступенки для спиральной лестницы не строятся (винтовые криволинейные
подступенки вне объёма v1, EDR-0007 §8).

## Входные параметры (SSOT, единицы ADR-0008)

| Symbol | Description | Unit |
|--------|-------------|------|
| H | общая высота подъёма (rise) | mm |
| W | ширина марша (расстояние колонна → наружная кромка) | mm |
| R | наружный радиус марша | mm |
| h0 | целевая высота ступени (riser) | mm |
| S | шаг комфорта (пользовательская или нормативная константа) | mm |
| α_total | полный угол поворота (константа: 360° = 2π) | rad |
| t | толщина косоура (stringer) | mm |
| st | толщина ступени (step thickness, EDR-0004) | mm |
| cl | вертикальный просвет (clearance) | mm |
| rh | высота ограждения (railing height) | mm |

## Выходные значения

| Symbol | Description | Unit |
|--------|-------------|------|
| n | число ступеней | шт. (int) |
| h | уточнённая высота ступени | mm |
| r | радиус колонны (= R − W) | mm |
| R | наружный радиус марша | mm |
| δ | угловой шаг одной ступени | rad |
| r_walk | радиус линии хода (= r + 2/3·W) | mm |
| b_walk | проступь по линии хода (= δ·r_walk) | mm |
| b_in | проступь у колонны (= δ·r) | mm |
| b_out | проступь у наружной кромки (= δ·R) | mm |
| α | угол подъёма винтовой линии (= atan(h / b_walk)) | deg (отображение) |
| L | длина дуги марша по наружной кромке (= δ·R·n) | mm |

# 4. Formulas

Все вычисления на `float64`, без внутренних округлений (ADR-0008).
Точность геометрии — 1e-6 мм. Округления допускаются только на границе
(отображение, документация, API).

## 4.1 Число ступеней

```
n = round(H / h0)          (n ≥ 1, целое)
```

## 4.2 Уточнённая высота ступени

```
h = H / n
```

## 4.3 Полный угол и угловой шаг

Полный оборот — константа:

```
α_total = 2π (360°)
δ = α_total / n            (рад, угловой шаг ступени)
```

## 4.4 Радиусы

```
r = R − W                  (радиус колонны, r > 0)
r_walk = r + (2/3)·W       (линия хода)
```

Инварианты:

```
R > W                      (колонна имеет положительный радиус)
r > 0
```

## 4.5 Проступи (по радиусу)

```
b_in   = δ·r
b_walk = δ·r_walk
b_out  = δ·R
```

Инварианты:

```
b_in   ≥ 100 мм            (у колонны проступь не должна исчезать)
b_walk ∈ 260..320 мм       (правило GEO-TREAD-DEPTH по линии хода)
b_out  ≥ 250 мм
```

## 4.6 Угол подъёма винтовой линии

```
α = atan(h / b_walk)
```

Внутренняя единица угла — радиан; градусы только для отображения.
Правило GEO-ANGLE (EDR-0002) применяется к этому углу.

## 4.7 Длина дуги марша

```
L = δ·R·n                   (длина по наружной кромке)
```

## 4.8 Геометрия и раскладка

Центральная колонна — цилиндр радиуса `r` от пола (`z = 0`) до высоты
`H`: `{(x,y): x²+y² ≤ r²} × [0, H]`, роль `"column"`.

Ступень `k` (k = 0..n−1) — сектор кольца:

```
{x²+y² ∈ [r², R²]} × [k·h, k·h + st]
```

повёрнутый на угол `k·δ` вокруг оси Z, роль `"tread"`. Верх проступи —
на высоте `(k+1)·h`, толщина `st` вниз (как EDR-0004): ступень `k`
занимает `z ∈ [(k+1)·h − st, (k+1)·h]`.

Дуги сегментируются полигоном (8 сегментов на клин) — аппроксимация
окружности многоугольником; объём ступени = площадь сектора × `st`.

Подступенки не строятся (EDR-0007 §8).

# 5. Determinism

Формулы детерминированы: при равных входных параметрах результат строго
идентичен (наследует детерминизм EDR-0001). Сегментация дуг фиксирована.

Порядок пересчёта результата через Graph Scheduler (ADR-0012):
предки → потомки, каждый узел выполняется не более одного раза за проход.

---

# 6. Precision

- входные/выходные значения: `float64`;
- геометрическая точность: 1e-6 мм;
- сегментация дуги: 8 сегментов на клин (полигональная аппроксимация);
- никаких промежуточных округлений внутри расчёта.

---

# 7. Tests

- Unit тесты формул (каждый пункт §4);
- determinism: повторный запуск даёт идентичный результат;
- edge cases: n < 1 → ошибка; R ≤ W → ошибка; b_in < 100 → ошибка;
  S вне диапазона 600–640 → ошибка;
- интеграция с Validation Engine (EDR-0003): правила EDR-0002
  применяются к линии хода (b_walk) и углу подъёма винтовой линии.

# 8. Acceptance Criteria

- Формулы реализованы в `internal/engine/solver` строго по §4;
- единицы соответствуют ADR-0008;
- спиральная конфигурация проходит полный конвейер
  (Solver → Validation → Geometry → Manufacturing → Pricing);
- результат пересчитывается инкрементально через Graph Engine;
- Manufacturing поддерживает новую роль детали «колонна» (PartColumn);
- подступенки не строятся (вне объёма v1).
