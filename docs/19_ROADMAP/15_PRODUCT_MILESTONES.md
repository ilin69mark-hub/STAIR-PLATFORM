# Purpose

Определяет Product Milestones.

---

# PM-01 — Project Management

Пользователь может:

* Создать проект
* Открыть проект
* Изменить проект
* Удалить проект

---

# PM-02 — Stair Configuration

Пользователь может:

* Создать конфигурацию лестницы
* Изменить параметры
* Сохранить конфигурацию
* Проверить ограничения

---

# PM-03 — Calculation

Пользователь получает:

* Расчет параметров
* Результат validation
* Информацию об ошибках

---

# PM-04 — Geometry

Пользователь получает:

* Parametric geometry
* Геометрическую модель
* Измерения
* Validation status

---

# PM-05 — Manufacturing

Пользователь получает:

* Parts
* BOM
* Materials
* Manufacturing data

---

# PM-06 — Pricing

Пользователь получает:

* Material cost
* Labor cost
* Additional costs
* Final price

---

# PM-07 — Export

Пользователь может экспортировать:

* Geometry
* Manufacturing data
* BOM
* Pricing data
* Required documents

---

# PM-08 — AI Assistance

Пользователь может использовать AI для:

* Анализа конфигурации
* Подсказок
* Поиска ошибок
* Работа с engineering workflow

---

# PM-09 — Production Product

Пользователь может пройти полный workflow без участия разработчика.

---

# Acceptance Criteria

Каждый Product Milestone соответствует конкретной пользовательской capability.
