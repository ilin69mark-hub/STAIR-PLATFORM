# Purpose

Определяет Definition of Done для Project Phases.

---

# General Definition of Done

Phase считается завершенной только если:

Scope реализован

Critical Requirements выполнены

Tests пройдены

Documentation актуальна

Known Critical Defects отсутствуют

Dependencies стабилизированы

Acceptance Criteria выполнены

---

# Foundation DoD

Foundation считается завершенным если:

Architecture documented

Principles documented

ADR process defined

Development process defined

Standards defined

Glossary defined

---

# Domain DoD

Domain считается завершенным если:

Entities defined

Relationships defined

Business Rules implemented

Invariants tested

Domain Tests pass

---

# Engine DoD

Engine считается завершенным если:

Calculation Pipeline работает

Constraints работают

Validation работает

Critical Algorithms tested

Performance baseline установлен

---

# Geometry DoD

Geometry считается завершенной если:

Parametric Model работает

Coordinate System определен

Constraints работают

Geometry Validation работает

Critical Geometry Tests pass

---

# Manufacturing DoD

Manufacturing считается завершенным если:

Parts generated

BOM generated

Materials assigned

Manufacturing validation works

Required output formats supported

---

# Pricing DoD

Pricing считается завершенным если:

Cost model implemented

Pricing rules implemented

Rounding policy implemented

Historical pricing protected

Tests pass

---

# API DoD

API считается завершенным если:

Contracts defined

Authentication implemented

Authorization implemented

Validation implemented

Error model implemented

API tests pass

---

# Backend DoD

Backend считается завершенным если:

Application services implemented

Repositories implemented

Background jobs implemented where required

Observability integrated

Tests pass

---

# Frontend DoD

Frontend считается завершенным если:

Critical workflows implemented

API integration complete

Validation implemented

Error states handled

E2E tests pass

---

# AI DoD

AI считается завершенным если:

AI Gateway implemented

Provider abstraction implemented

Tool permissions implemented

Safety controls implemented

AI evaluation tests pass

---

# Production DoD

Production считается готовым если:

Infrastructure deployed

Monitoring active

Alerts configured

Backups verified

Security checks passed

Recovery procedure verified

Critical E2E tests passed

---

# Acceptance Criteria

Каждая Phase имеет explicit Definition of Done.
