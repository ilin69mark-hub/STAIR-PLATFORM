# Purpose

Определяет Acceptance Testing Strategy.

---

# Objective

Подтвердить, что реализованная система соответствует установленным Product и Business Requirements.

---

# Acceptance Sources

Acceptance Tests строятся на основании:

Product Requirements

Business Rules

User Stories

Use Cases

Acceptance Criteria

Domain Rules

---

# Acceptance Levels

Feature Acceptance

Workflow Acceptance

System Acceptance

Release Acceptance

---

# Feature Acceptance

Проверяется отдельная capability.

Пример:

Создание проекта.

---

# Workflow Acceptance

Проверяется полный business workflow.

Пример:

Project
 ↓
Configuration
 ↓
Geometry
 ↓
Manufacturing
 ↓
