# Purpose

Semantic Model связывает геометрию с инженерным смыслом.

Он отвечает на вопрос:

"Что представляет собой данный объект?"

а не

"Как он выглядит?"

---

# Semantic Object

Каждый объект модели содержит:

Geometry

+

Engineering Meaning

+

Manufacturing Meaning

+

Business Meaning

---

# Example

STEP_001

↓

Type = Step

↓

Material = Oak

↓

Finish = Oil

↓

Manufacturing = CNC

↓

Installation = Bolt

↓

Load Bearing = Yes

↓

Replaceable = Yes

# Rules

Семантика существует независимо от геометрии.

Изменение геометрии не должно изменять инженерный смысл объекта.
