# 1. Purpose

Настоящий документ определяет ценностное предложение Stair Platform.

Документ отвечает на вопрос:

> Почему клиенты должны выбрать Stair Platform вместо существующих решений.

Value Proposition используется при:

- разработке продукта;
- формировании маркетинговых материалов;
- построении стратегии продаж;
- определении Product Roadmap;
- приоритизации функций.

---

# 2. Core Value Proposition

Stair Platform предоставляет единое цифровое пространство для полного жизненного цикла лестницы — от первой идеи до производства и монтажа.

Платформа заменяет множество разрозненных инструментов единой инженерной системой.

---

# 3. Customer Value

Используя Stair Platform, клиент получает возможность:

- проектировать лестницы быстрее;
- автоматически выполнять инженерные расчеты;
- получать корректные спецификации;
- рассчитывать стоимость изделия;
- автоматически формировать документацию;
- передавать проект в производство;
- сопровождать заказ до завершения.

Все процессы выполняются в рамках одной платформы.

# 5. Pain Points

Основные проблемы пользователей.

## Engineering

- ручные расчеты;
- ошибки проектирования;
- сложность проверки ограничений.

---

## Commercial

- длительная подготовка КП;
- ошибки расчета стоимости;
- отсутствие единой информации.

---

## Manufacturing

- ошибки передачи данных;
- ручное формирование спецификаций;
- отсутствие автоматизации.

---

## Organization

- разрозненные программы;
- потеря информации;
- отсутствие единого процесса.
