# 3. Key Financial Metrics

Используются следующие показатели.

## Customer Acquisition Cost (CAC)

Стоимость привлечения одного клиента.

Формула:

```
CAC =
(Sales Costs + Marketing Costs)
/ New Customers
```

---

## Lifetime Value (LTV)

Доход, который приносит клиент за весь период использования платформы.

Формула:

```
LTV =
ARPU × Average Customer Lifetime
```

---

## LTV / CAC Ratio

Показывает эффективность модели.

Формула:

```
LTV / CAC
```

Целевое значение:

```
> 3
```

---

## Payback Period

Срок окупаемости стоимости привлечения клиента.

Формула:

```
CAC / Monthly Gross Profit
```

Целевое значение:

```
< 12 месяцев
```

---

## Gross Margin

Формула

```
Revenue - Direct Costs
```

Целевое значение

```
> 80%
```
