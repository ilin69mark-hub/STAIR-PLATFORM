# Purpose

Nesting Engine оптимизирует размещение деталей на листовом или профильном материале перед изготовлением.

---

# Objectives

- минимизация отходов;
- сокращение времени раскроя;
- уменьшение стоимости производства;
- эффективное использование материала.
