# Purpose

Tolerance Engine определяет допустимые производственные отклонения и проверяет соответствие деталей требованиям проекта.

---

# Objectives

- единое хранение допусков;
- проверка технологической реализуемости;
- предотвращение производственных ошибок.

# Validation

Engine проверяет:

- допустимость значения;
- совместимость с материалом;
- совместимость с оборудованием;
- достижимость выбранной технологией.
