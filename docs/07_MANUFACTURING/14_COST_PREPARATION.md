# Purpose

Cost Preparation формирует исходные производственные данные,
необходимые для последующего расчета стоимости изделия.

Расчет стоимости выполняется исключительно в разделе Pricing.

---

# Objectives

Подготовить:

- расход материалов;
- машинное время;
- трудоемкость;
- количество операций;
- количество комплектующих;
- массу изделия;
- производственные коэффициенты.

---

# Inputs

Material Assignment

Machine Operations

Assembly

BOM

Manufacturing Metadata

---

# Generated Metrics

Material Consumption

Waste

Estimated Labor Time

Operation Count

Part Count

Fastener Count

Surface Area

Volume

Mass

---

# Output

Manufacturing Cost Dataset

Pricing Input Package

Production Statistics

---

# Rules

Cost Preparation не содержит:

- цены;
- тарифы;
- коммерческие коэффициенты;
- прибыль;
- налоги.

---

# Acceptance Criteria

- подготовка полного набора производственных параметров;
- отсутствие финансовых расчетов;
- совместимость с Pricing Platform.
