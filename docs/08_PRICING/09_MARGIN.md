# Purpose

Margin Engine определяет коммерческую наценку на изделие.

---

# Objectives

- поддержка различных стратегий маржинальности;
- настройка правил без изменения кода;
- поддержка нескольких каналов продаж.

# Margin Rules

Каждая стратегия может зависеть от:

- клиента;
- региона;
- объема заказа;
- категории изделия;
- коммерческой политики.

- полная трассируемость расчета.
