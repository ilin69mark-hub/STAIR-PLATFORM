# Purpose

Material Cost Engine рассчитывает стоимость материалов изделия.

---

# Inputs

Material Assignment

Material Library

Supplier Prices

Waste Report

Currency

---

# Cost Components

Base Material

Waste

Coating

Surface Treatment

Transportation

Storage

Supplier Fees

---

# Calculation

Стоимость определяется на основании:

- количества;
- единицы измерения;
- актуальной цены;
- коэффициентов потерь;
- региональных настроек.

---

# Supported Units

Piece

Meter

Square Meter

Cubic Meter

Kilogram

Ton

Liter

---

# Output

Material Cost

Material Breakdown

Waste Cost

Supplier Summary

---

# Acceptance Criteria

- поддержка различных единиц измерения;
- поддержка нескольких поставщиков;
- полная трассируемость стоимости.
