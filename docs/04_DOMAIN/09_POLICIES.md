# Purpose

Policies определяют бизнес-правила, регулирующие поведение доменной модели.

Policy отвечает на вопрос:

"Какие правила должны соблюдаться?"

---

# Policy Principles

Policy:

- не хранит состояние;
- может использовать несколько Aggregate;
- не зависит от UI;
- не зависит от БД;
- является частью Domain Layer.
