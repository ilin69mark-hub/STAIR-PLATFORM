# Global Rules

Все изменения выполняются только через Aggregate Root.

---

Все Value Objects immutable.

---

Entity не существует вне Aggregate.

---

Aggregate публикует Domain Events.

---

Все инженерные расчеты выполняются только после Validation.

---

Все документы создаются только для утвержденной ревизии.

---

Все производственные данные должны быть трассируемыми.

---

Все AI-рекомендации должны быть объяснимыми.

---

Каждый объект имеет полный Audit Trail.

---

Каждая ревизия проекта неизменяема после публикации.
