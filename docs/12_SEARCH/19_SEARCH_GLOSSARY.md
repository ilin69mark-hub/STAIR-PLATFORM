# Terms

Search Object

Индексируемое представление инженерного объекта.

---

Index

Структура данных для быстрого поиска.

---

Query

Поисковый запрос пользователя или сервиса.

---

Ranking

Алгоритм упорядочивания результатов поиска.

---

Filter

Ограничение области поиска.

---

Autocomplete

Механизм формирования поисковых подсказок.

---

Semantic Search

Поиск по смысловому сходству с использованием векторных представлений.

---

Hybrid Search

Комбинация нескольких механизмов поиска (Full Text, Graph, Geometry, Semantic).

---

Facet

Агрегированная характеристика результатов поиска для построения фильтров.

---

Search Orchestrator

Компонент Query Engine, определяющий стратегию выполнения поискового запроса.
