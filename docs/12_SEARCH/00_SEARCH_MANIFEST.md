# Purpose

Search Layer обеспечивает быстрый поиск инженерных объектов, документов, параметров, графов зависимостей и производственных данных.

Search не является источником истины.

Search работает только с индексами.

---

# Objectives

- быстрый поиск;
- масштабируемость;
- полнотекстовый поиск;
- семантический поиск;
- геометрический поиск;
- фильтрация;
- ранжирование.
