# 1. Context

Stair Platform является инженерной CAD-платформой.

Все вычисления Geometry Engine, Solver, Constraint Engine, Validation Engine и Manufacturing должны использовать единую математическую модель пространства.

Несогласованность единиц измерения или координатных систем приводит к ошибкам проектирования, экспорта и производства.

Необходимо определить единый инженерный стандарт.

---

# 2. Problem

Без единого стандарта возникают:

- ошибки преобразования размеров;
- ошибки поворотов;
- несовместимость CAD;
- ошибки импорта DXF/STEP;
- ошибки генерации CNC;
- накопление ошибок округления.

---

# 3. Decision

Во всей Stair Platform используется единая инженерная математическая модель.

Все инженерные расчеты выполняются исключительно в базовой внутренней системе координат.

---

# 5. Coordinate System

Используется правая декартова система координат.

```
          Z
          ↑
          │
          │
          │
          │
          └────────► X

         /
        /
       ▼

      Y
```

---

Направления осей

```
X → вправо

Y → вперед

Z → вверх
```

---

# 6. Origin

Начало координат

```
(0,0,0)
```

располагается в базовой точке проекта.

Все элементы строятся относительно Origin либо относительно локальной системы координат.

---

# 7. Local Coordinate Systems

Каждый объект может иметь собственную локальную систему координат.

Локальная система хранит:

- Translation
- Rotation
- Scale

Глобальные координаты вычисляются посредством преобразования.

---

# 8. Transformations

Поддерживаются:

- Translation
- Rotation
- Mirror
- Scale
- Matrix Transform

Все преобразования используют матрицы 4×4.

---

# 9. Precision

Тип хранения

```
float64
```

Точность внутренних вычислений

```
0.000001 mm
```

---

# 10. Tolerance

Инженерная погрешность

```
±0.1 mm
```

Производственная погрешность определяется отдельно в Manufacturing Rules.

---

# 11. Rounding

Во внутренних вычислениях округление запрещено.

Округление допускается исключительно:

- при отображении;
- при печати;
- при генерации документации.

---

# 12. CAD Compatibility

Все CAD-конвертеры обязаны использовать настоящую систему координат.

Поддерживаемые форматы:

- DXF
- STEP
- STL
- SVG
- PDF

---

# 13. Geometry Rules

Geometry Engine обязан:

- использовать исключительно float64;
- избегать накопления ошибок;
- быть детерминированным;
- обеспечивать воспроизводимость вычислений.

---

# 14. Validation

Перед сохранением модели проверяются:

- корректность координат;
- отсутствие NaN;
- отсутствие Infinity;
- допустимые диапазоны;
- корректность матриц преобразования.

---

# 15. Consequences

Преимущества:

- единая инженерная модель;
- совместимость CAD;
- единая система преобразований;
- отсутствие неоднозначностей;
- стабильность Solver.

Недостатки:

- необходимость конвертации внешних единиц измерения.

---

# 16. Alternatives Considered

## Сантиметры

Отклонено.

Недостаточная точность.

---

## Метры

Отклонено.

Не соответствуют инженерной практике мебельного и лестничного производства.

---

## float32

Отклонено.

Недостаточная точность для геометрических вычислений.

---

# 17. Implementation

После принятия ADR:

- Geometry Engine использует только mm;
- Solver использует только mm;
- Constraint Engine использует только mm;
- все CAD-конвертеры выполняют преобразование единиц при импорте и экспорте;
- UI автоматически преобразует единицы отображения при необходимости.
