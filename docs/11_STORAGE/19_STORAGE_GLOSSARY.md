# Purpose

---

# Terms

Storage Object

Бинарный объект, управляемый Storage Layer.

---

Object Storage

S3-совместимое хранилище бинарных объектов.

---

Binary Object

Физическое содержимое файла.

---

Metadata

Структурированные данные, описывающие объект хранения.

---

Archive

Долговременное хранилище объектов только для чтения.

---

Replication

Копирование объектов между независимыми хранилищами.

---

Checksum

Контрольная сумма для проверки целостности объекта.

---

Multipart Upload

Механизм загрузки больших файлов частями.

---

Signed URL

Временная ссылка для безопасного доступа к объекту.

---

Storage Version

Неизменяемая версия бинарного объекта.
