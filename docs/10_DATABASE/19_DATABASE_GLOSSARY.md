# Terms

Aggregate

Основная единица хранения предметной области.

---

Repository

Интерфейс доступа к данным.

---

Revision

Неизменяемая инженерная ревизия объекта.

---

Version

Историческая запись состояния объекта.

---

Snapshot

Материализованное состояние объекта для быстрого восстановления.

---

Event Store

Хранилище Domain Events.

---

Audit

Журнал изменений системы.

---

Graph Node

Узел графа зависимостей.

---

Graph Edge

Связь между узлами графа.

---

Metadata

Дополнительные данные объекта, не влияющие на вычисления.

---

Property

Инженерское свойство объекта.

---

Attribute

Описательная характеристика объекта.
