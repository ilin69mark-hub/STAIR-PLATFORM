# Terms

AI Runtime

Среда выполнения AI-запросов.

---

Provider

Адаптер конкретной AI-модели или сервиса.

---

Model Router

Компонент выбора оптимальной модели.

---

Prompt

Структурированный запрос к AI-модели.

---

Context

Совокупность данных, передаваемых модели для решения задачи.

---

RAG

Retrieval Augmented Generation — механизм дополнения запроса релевантными знаниями из платформы.

---

Tool Calling

Безопасный механизм вызова сервисов платформы AI.

---

Agent

Специализированный исполнитель, работающий через Runtime и Tool Calling.

---

Planning

Декомпозиция сложной задачи на последовательность исполнимых шагов.

---

Inference

Процесс получения результата от AI-модели.
