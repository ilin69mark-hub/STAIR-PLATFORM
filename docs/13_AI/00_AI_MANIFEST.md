# Purpose

AI Layer предоставляет интеллектуальные сервисы платформы и обеспечивает взаимодействие пользователей, инженерных моделей и внешних AI-моделей.

AI Layer не содержит предметную бизнес-логику и не является источником истины.

---

# Objectives

- интеллектуальная помощь инженеру;
- автоматизация проектирования;
- генерация инженерной документации;
- анализ моделей;
- рекомендации;
- AI Automation;
- Agent Framework;
- Tool Calling;
- Retrieval Augmented Generation (RAG).
