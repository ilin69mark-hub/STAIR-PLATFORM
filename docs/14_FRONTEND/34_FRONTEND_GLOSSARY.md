# Purpose

# Terms

Application Shell

Основная оболочка клиентского приложения.

---

Workspace

Рабочее пространство пользователя.

---

Canvas

Интерактивная область визуализации инженерной модели.

---

Viewport

Область отображения текущего вида сцены.

---

Command

Стандартизированное действие пользователя или AI.

---

Selection Context

Единый контекст выбранных объектов.

---

Rendering Engine

Компонент визуализации инженерных данных.

---

Server State

Данные, принадлежащие Backend.

---

Client State

Состояние, принадлежащее Frontend.

---

Feature Module

Изолированный функциональный модуль Frontend.

---

Realtime Event

Событие, доставляемое клиенту без явного запроса.
