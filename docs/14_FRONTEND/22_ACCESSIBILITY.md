# Purpose

Определяет требования доступности интерфейса.

---

# Objectives

Доступность основных функций для пользователей с различными ограничениями.

---

# Requirements

Keyboard Navigation

Focus Management

ARIA

Readable Contrast

Semantic HTML

Screen Reader Support

Reduced Motion

---

# Workspace Accessibility

Panels должны быть доступны через клавиатуру.

Command Palette должна поддерживать keyboard navigation.

Critical actions должны иметь accessible labels.

---

# Canvas Accessibility

Основные действия Canvas должны иметь альтернативное UI-представление.

Geometry не должна быть доступна только через визуальный Canvas.

---

# Rules

Accessibility учитывается на этапе разработки компонента.

---

# Acceptance Criteria

Ключевые сценарии доступны без использования мыши.
