# Purpose

Определяет Definition of Done для development tasks.

---

# Code

* [ ] Implementation complete
* [ ] Code formatted
* [ ] Static analysis passed
* [ ] No unresolved debug code

---

# Tests

* [ ] Required unit tests passed
* [ ] Required integration tests passed
* [ ] Required API tests passed
* [ ] Required E2E tests passed

---

# Architecture

* [ ] Architectural boundaries preserved
* [ ] Required ADR created
* [ ] Dependencies reviewed

---

# Database

Если применимо:

* [ ] Migration created
* [ ] Migration tested
* [ ] Compatibility verified

---

# API

Если применимо:

* [ ] Contract updated
* [ ] Validation implemented
* [ ] Documentation updated

---

# Security

* [ ] Authorization verified
* [ ] Sensitive data protected
* [ ] No secrets committed

---

# Documentation

Если изменение влияет на documentation:

* [ ] Documentation updated
* [ ] Related references updated

---

# Review

* [ ] Pull Request created
* [ ] Code Review completed
* [ ] Blocking comments resolved

---

# CI

* [ ] Mandatory CI checks passed

---

# Integration

* [ ] Change merged according to repository policy

---

# Final Condition

Development Task считается Done только после выполнения всех применимых критериев.
